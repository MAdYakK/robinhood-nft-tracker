# Robinhood Chain NFT Mint Tracker Skill

This skill enables your Bankr agent (on terminal, web, and @bankrbot on X/Twitter) to track and report live NFT mints on Robinhood Chain.

## Features
- Detects fresh ERC-721 and ERC-1155 mint events
- Filters free vs paid mints
- Tracks mint velocity and unique minter momentum

## Installation
In Bankr terminal or via @bankrbot on X:
`install skill from https://github.com/<your-username>/robinhood-nft-tracker`
